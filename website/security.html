Intended use Invited & authorized users
1

Protecting Your Information

FinSight handles personal expense and budgeting information. Protecting this information is an important part of operating the application.

verified_user FinSight is intended for a limited group of invited users.
2

Account Security

Users should:

key Keep their login credentials private.
password Use strong, unique passwords.
group_off Avoid sharing their accounts.
logout Log out when using shared devices.
notification_important Report suspicious account activity.
3

Data Protection

FinSight uses Supabase for application data storage and a Flask backend to process application requests.

Access to personal financial records and chatbot conversations should be restricted to authorised users. The operator may access information when necessary for maintenance, support, or security.

4

AI Chatbot Security

FinSight uses Groq for AI chatbot responses. Relevant messages and financial context may be processed by the AI provider.

warning
Important Security Notice:

Never enter bank passwords, card PINs, CVVs, UPI PINs, OTPs, or other sensitive authentication details into the chatbot.

5

Application Security

We aim to protect FinSight through appropriate safeguards, including:

lock Secure HTTPS connections.
admin_panel_settings Server-side authentication and access controls.
fact_check Input validation.
vpn_key Restricted access to application data and secrets.
published_with_changes Regular maintenance and security updates.
settings_backup_restore Appropriate backups and recovery procedures.
info

No online service can guarantee complete protection against every security threat.

6

7

Security Updates

We may update our security practices as FinSight develops. This page will be updated when there are relevant changes.
